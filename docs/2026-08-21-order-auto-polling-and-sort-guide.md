# 2026-08-21 주문 관리 실시간 자동 갱신(Polling) 및 정렬 개선

## 1. 개요
- 사장님이 별도로 새로고침(F5)을 누르지 않아도, 소비자가 주문을 넣는 즉시 4초 주기로 자동 조회되어 홈 및 주문 관리 목록에 노출되도록 개선.

---

## 2. 주요 변경 사항 (`MakeAWish-FE-Owner`)
1. **`pages/orders/OrderList.jsx`**:
   - 4초 주기 polling (`setInterval`) 적용
   - 최신 주문(ID 기준)이 상단에 위치하도록 내림차순 정렬
2. **`pages/home/Home.jsx`**:
   - 홈 화면 오늘의 주문 4초 주기 자동 갱신 적용
