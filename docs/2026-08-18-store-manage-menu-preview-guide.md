# 2026-08-18 매장 관리 메뉴 목록 미리보기 및 가격 연동 가이드

## 1. 개요
- **목적**: 사장님이 매장 관리(`StoreManage.jsx`) 페이지에서 현재 등록된 메뉴(카테고리) 목록과 기본 시작 가격을 한눈에 파악할 수 있도록 카드를 개선하고, [관리하기] 버튼 클릭 시 메뉴 관리 화면(`/menus`)으로 정확히 이동하여 가격 및 설명을 편집할 수 있도록 지원합니다.

## 2. 주요 수정 사항
- **대상 파일**: `MakeAWish-FE-Owner/src/pages/store/StoreManage.jsx`
- **구현 내용**:
  - `profile.categories` 배열을 순회하여 각 메뉴의 이름과 포맷팅된 시작 가격(예: `18,000원~`) 뱃지 렌더링.
  - [관리하기] 클릭 시 `/menus` (`MenuManager.jsx`)로 라우팅 연결.
