# 2026-08-21 사장님 앱 포트폴리오 대표 태그 UX 가이드 및 순서 보존 적용

## 1. 개요
- **배경**: 소비자 앱 메인 피드의 카드 좌측 상단에는 사장님이 등록한 태그 중 첫 번째 태그(1번 태그)가 **대표 뱃지**로 표출됨.
- **개선 목적**: 사장님이 도안(포트폴리오)을 등록하거나 수정할 때 어떤 태그가 대표 뱃지로 나가는지 직관적으로 인지하고, 원하는 태그를 손쉽게 대표 태그로 지정할 수 있도록 UX를 개선함.

---

## 2. 주요 변경 사항
1. **`PortfolioForm.jsx`**:
   - `💡 첫 번째 태그는 소비자 앱 카드 좌측 상단에 대표 뱃지로 노출됩니다.` 안내 가이드 추가
   - 1번 태그에 `⭐ 대표` 뱃지 및 분홍색 강조 스타일 적용
   - 2번 이후의 태그에는 `대표로 설정` 버튼을 제공하여 클릭 한 번으로 손쉽게 1순위로 승격 이동 가능
2. **`PortfolioList.jsx`**:
   - 포트폴리오 목록 카드에서 1번 태그에 `⭐ #태그명` 분홍색 뱃지를 적용하여 대표 태그가 무엇인지 한눈에 파악 가능
3. **`MakeAWish-BE` (`Portfolio.java`, `PortfolioService.java`)**:
   - `LinkedHashSet`을 적용하여 사장님이 등록한 태그의 순서가 DB 저장 및 조회 시 그대로 100% 보존되도록 개선
