# 2026-08-18 메뉴(카테고리) 기본 가격 설정 모달 개편 및 연동 가이드

## 1. 개요 및 배경
- **문제점**: 이전 사장님 앱의 메뉴 관리 화면(`MenuManager.jsx`)에서는 브라우저 기본 `window.prompt`로 메뉴 이름만 입력받았으며, API 전송 시 가격이 `price: 0`으로 하드코딩되어 있었습니다.
- **영향**: 기본 케이크 가격이 0원으로 설정되어 주문 생성 시 기준 가격이 없어 추가금으로만 총 결제 금액을 구성해야 하는 비정상적인 결제 흐름이 발생했습니다.
- **개선 목표**:
  1. `window.prompt`를 제거하고 모던하고 완성도 높은 **커스텀 모달 컴포넌트(`MenuModal.jsx`)** 도입
  2. 메뉴 이름뿐만 아니라 **기본 시작 가격(price)** 및 **설명(description)**을 입력 및 수정 가능하도록 개편
  3. 메뉴 목록 UI에서 각 메뉴의 기본 가격(`15,000원~`)과 설명을 직관적으로 확인할 수 있도록 개선

---

## 2. 주요 변경 사항

### 2.1. `MenuModal.jsx` 컴포넌트 신규 개발
- 경로: `src/components/ui/MenuModal.jsx`
- **주요 기능**:
  - `isOpen`, `onClose`, `onSubmit`, `initialData`, `loading` 속성을 받아 추가 및 수정 모드를 유연하게 지원
  - 가격 입력 시 숫자 이외의 문자 입력 방지 및 실시간 천 단위 콤마 포맷팅(`toLocaleString()`) 제공
  - 유효성 검사(필수 이름 입력 확인, 음수 가격 방지 등) 에러 메시지 렌더링

### 2.2. `MenuManager.jsx` 화면 연동
- 경로: `src/pages/store/MenuManager.jsx`
- **개선점**:
  - `handleOpenAddModal` 및 `handleOpenEditModal` 핸들러로 모달 상태 제어
  - 백엔드 상품 생성(`createProduct`) 및 수정(`updateProduct`) API 호출 시 실제 입력된 가격과 설명 데이터를 안전하게 전송
  - 메뉴 카드 UI에 기본 가격 뱃지(`{price}원~`) 및 설명 텍스트 표시

## 3. 데이터 흐름 및 결제 연동 시나리오

```
[사장님 앱 (MenuManager)]
  ➔ 메뉴 등록: 도시락 케이크 / 기본 가격: 18,000원 설정
  ➔ POST /api/stores/{storeId}/products
       { "name": "도시락 케이크", "price": 18000, "description": "1~2인용 미니 케이크" }

[소비자 앱 (주문 생성 및 결제)]
  ➔ 소비자가 해당 메뉴 선택 시 기준 금액 18,000원에서 출발
  ➔ 사장님이 옵션 확인 후 추가금 2,000원 책정 시 totalPrice = 20,000원
  ➔ 토스페이먼츠 결제창에 20,000원 전달 후 결제 완료 (PAID)
```
